## Hotkeys

In `planck.SC2Hotkeys` are my SC2 hotkeys tkeys that will probably make no
sense to anyone but me. These are setup for a Planck keyboard

see https://github.com/willbush/keebs for my Planck keyboard firmware config.

This is basically using Grid layout with some manual tweaks to unit spell casts
to make them more ergonomics or less bad. For example explode bane on the same
key that morphs banes is not good.
